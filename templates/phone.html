Voice, from your watch · set up once

Two things to copy into the Shortcuts app. They are yours: don't share them.

1 · Address

{{ siri_url }}

2 · Header value (key: Authorization)

{{ siri_header }}
  1. Shortcuts → + → add Dictate Text.
  2. Add Get Contents of URL: paste the address; Show More → Method POST; Headers → Add: key Authorization, value: paste the header value; Request Body File → choose Dictated Text.
  3. Add Speak Text (it speaks the Contents of URL).
  4. Name it Carpe Vigor; ⓘ → Show on Apple Watch.
  5. Start what you say with “log” (in Italian “segna”): “log a pizza margherita”. Dictation tends to lose the first word; this one can go.
Steps and exercise minutes · every evening

Your iPhone and Apple Watch already count your steps and exercise minutes. This shortcut sends today's to Carpe Vigor each evening: nothing to type. First give your consent on Measures (on the computer).

Address

{{ health_url }}

The header value is the same as for Siri, above.

  1. Shortcuts → + → add Find Health Samples: type Steps, Start Date is today, Group By Day.
  2. Add another Find Health Samples: type Exercise Minutes, Start Date is today, Group By Day.
  3. Add Get Contents of URL: paste the address; Method POST; Headers → Authorization = the header value; Request Body JSON with two fields: steps = the first Health Samples, exercise_min = the second.
  4. Add Get Dictionary Value “spoken” → Show Notification. Name it Carpe Vigor Health and run it once by hand.
  5. Automation → + → Time of Day 21:30, Daily, Run Immediately → Carpe Vigor Health.

Kept only with your consent; you can delete it on Measures. Weight never counts toward the reward.
